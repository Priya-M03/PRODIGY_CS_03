# 🔐 PRODIGY_CS_03 - Password Complexity Checker

## 📌 Overview

The **Password Complexity Checker** is a cybersecurity project developed as part of the **PRODIGY InfoTech Internship**.  
This tool evaluates the strength of a password based on multiple security criteria such as:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

It provides users with feedback and suggestions to improve password security, helping create stronger and safer passwords.

---

## 🚀 Features

✅ Checks password strength  
✅ Detects weak passwords  
✅ Verifies uppercase & lowercase usage  
✅ Checks numeric characters  
✅ Detects special characters  
✅ Gives improvement suggestions  
✅ Simple and user-friendly interface

---

## 🛠️ Technologies Used

- Python
- Regular Expressions (`re` module)
